See the [bluetooth feature page](../features/bluetooth.md) for more details on the general Bluetooth functionality in ZMK.

See [Configuration Overview](index.md) for instructions on how to change these settings.

## Kconfig

| Option                                             | Type | Description                                                                                                                                                                                                                                     | Default |
| -------------------------------------------------- | ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| `CONFIG_ZMK_BLE_EXPERIMENTAL_CONN`                 | bool | Enables a combination of settings that are planned to be default in future versions of ZMK to improve connection stability. Currently this only disables 2M PHY support.                                                                        | n       |
| `CONFIG_ZMK_BLE_EXPERIMENTAL_SEC`                  | bool | Enables a combination of settings that are planned to be officially supported in the future. This includes enabling BT Secure Connection passkey entry, and allows overwrite of keys from previously paired hosts.                              | n       |
| `CONFIG_ZMK_BLE_EXPERIMENTAL_FEATURES`             | bool | Aggregate config that enables both `CONFIG_ZMK_BLE_EXPERIMENTAL_CONN` and `CONFIG_ZMK_BLE_EXPERIMENTAL_SEC`.                                                                                                                                    | n       |
| `CONFIG_ZMK_BLE_PASSKEY_ENTRY`                     | bool | Enable six-digit passkey entry during pairing for enhanced security. Enter submits exactly six digits, Backspace removes the last digit, and Escape cancels. (Note: After enabling this, you will need to re-pair all previously paired hosts.) | n       |
| `CONFIG_ZMK_BLE_DIAGNOSTIC_HOOKS`                  | bool | Call weak hooks (see `zmk/hog.h`) on HID subscription and keyboard report delivery, for logging modules                                                                                                                                         | n       |
| `CONFIG_ZMK_BLE_ADV_TIMEOUT`                       | bool | Split central: pause advertising after the selected host has been away for `CONFIG_ZMK_BLE_ADV_TIMEOUT_MIN` minutes; a key press resumes it. The options below build on it                                                                      | n       |
| `CONFIG_ZMK_BLE_ADV_TIMEOUT_MIN`                   | int  | Minutes before advertising pauses                                                                                                                                                                                                               | 5       |
| `CONFIG_ZMK_BLE_ADV_BOOST`                         | bool | Advertise at 30-60 ms instead of 100-150 ms for `CONFIG_ZMK_BLE_ADV_BOOST_SEC` after a profile switch or resume                                                                                                                                 | n       |
| `CONFIG_ZMK_BLE_ADV_BOOST_SEC`                     | int  | Seconds of faster advertising                                                                                                                                                                                                                   | 12      |
| `CONFIG_ZMK_BLE_ADV_POST_SWITCH_DARK`              | bool | Pause advertising if the selected host doesn't connect during the boost                                                                                                                                                                         | n       |
| `CONFIG_ZMK_BLE_DIRECTED_ADV`                      | bool | After a profile switch, advertise directed to the selected host first                                                                                                                                                                           | n       |
| `CONFIG_ZMK_BLE_DIRECTED_ADV_SEC`                  | int  | Seconds of directed advertising                                                                                                                                                                                                                 | 4       |
| `CONFIG_ZMK_BLE_ADV_FILTER_ACTIVE_PROFILE`         | bool | Only the selected profile's host may connect (filter accept list)                                                                                                                                                                               | n       |
| `CONFIG_ZMK_BLE_RESELECT_RECONNECT`                | bool | Selecting the active profile again disconnects and re-advertises its host                                                                                                                                                                       | n       |
| `CONFIG_ZMK_BLE_IDLE_DISCONNECT`                   | bool | Disconnect the selected host and pause advertising after `CONFIG_ZMK_BLE_IDLE_DISCONNECT_MIN` minutes without a key press                                                                                                                       | n       |
| `CONFIG_ZMK_BLE_IDLE_DISCONNECT_MIN`               | int  | Minutes without a key press before disconnecting                                                                                                                                                                                                | 20      |
| `CONFIG_ZMK_BLE_EVICT_ADV_COOLDOWN_MS`             | int  | Delay advertising after another host disconnects                                                                                                                                                                                                | 0       |
| `CONFIG_ZMK_BLE_PROFILE_HANDOFF`                   | bool | Disconnect other hosts before advertising for a newly selected profile                                                                                                                                                                          | n       |
| `CONFIG_ZMK_BLE_PROFILE_HANDOFF_DISCONNECT_REASON` | hex  | HCI reason used for those disconnects                                                                                                                                                                                                           | 0x13    |
| `CONFIG_BT_GATT_ENFORCE_SUBSCRIPTION`              | bool | Low level setting for GATT subscriptions. Set to `n` to work around an annoying Windows bug with battery notifications.                                                                                                                         | y       |
| `CONFIG_BT_DEVICE_APPEARANCE`                      | int  | Bluetooth device [appearance value](https://bluetooth.com/specifications/assigned-numbers) (should be converted from hexadecimal to decimal).                                                                                                   | 961     |
